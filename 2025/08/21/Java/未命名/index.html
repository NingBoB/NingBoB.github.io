  • 三大特性是封装、继承和多态。多态是指相同的接口或方法在不同对象上表现出不同的行为。Java 中多态包括编译时多态（方法重载）和运行时多态（方法重写）。例如定义对象的时候用父类引用指向子类对象，在调用方法时，根据实际对象执行子类的实现。这让代码具有更好的扩展性和灵活性。

  • ArrayList和LinkedList之间的区别：实现不同、访问效率不同、插入删除的效率不同、占用空间不同、使用场景、存储效率

  • Synchronized和Reentrantlock的区别：实现不同（基于Monitor对象实现、AQS实现）、使用方式不同、获取锁的方式不同、是否公平、都可重入

  • 偏向锁、轻量级锁、重量级锁：相同线程、不同线程CAS并且无阻塞、CAS失败线程挂起

  • MVCC：隐藏字段、readView（活跃中的事务idlist、活跃中的最小事务id、最大事务id+1、创建该事物的id） 、undo log

  • 垂直分库：按业务划分、水平分库：将数据表中的数据存储到不同的数据库中、垂直分表：冷热字段分离、水平分表：对数据量大的表进行拆分。

  • B树和B+树：所有节点和仅叶子结点存数据、对范围查找的支持、矮胖。

  • MySQL查询流程：连接器、分析器、优化器、执行器、查缓存

  • 日志：undolog，回滚用，保证原子性，也用于MVCC；redolog，用于崩溃后事务重做，记录操作，顺序写入redolog文件，然后异步写入磁盘，而非直接磁盘；binlog，数据库的备份文件，用于主从、备份恢复等。

  • 多路复用：IO 多路复用是一种通过单线程监听多个 IO 的机制，将socket作为fd注册到内核

  • 什么是AOP：AOP 是面向切面编程，是一种将横切关注点（如日志、权限、事务）从业务代码中解耦的方式。它通过定义切面、切入点和通知等机制，在不改变原有业务逻辑的前提下实现功能增强。广泛用于日志记录、事务控制等场景。

  • 握手：

    • 客户端 → 服务端：发送一个 SYN 请求，表示要建立连接。
    • 服务端 → 客户端：回复一个 SYN+ACK，表示收到请求并同意连接。
    • 客户端 → 服务端：发送一个 ACK 确认，连接建立完成。

  • 挥手：

    • 客户端 → 服务端：发送 FIN，表示不再发送数据。
    • 服务端 → 客户端：回复 ACK，确认收到断开请求。
    • 服务端 → 客户端：发送 FIN，表示服务端也不再发送数据。
    • 客户端 → 服务端：回复 ACK，连接完全断开。
